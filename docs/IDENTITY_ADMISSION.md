# 五托管方预登记与至少两人会话准入

运行 `run_identity_gate_experiment.py`，先登记5个互不相同的身份承诺及公开的Schnorr知识证明，验证所有登记证明后，才建立本地门禁。每个会话至少需要两个互不相同的已登记托管方证明；证明通过 Fiat–Shamir 挑战绑定会话编号、周期、完整参与名单、基座哈希和本次随机挑战。重复编号、少于两人、未登记、缺失或篡改证明、跨会话重放均拒绝，失败不写入会话登记。

每个获准登记的参与方各获得一份有效份额；会话准入要求所列人员的身份证明全部有效。恢复门限固定为全部登记参与方均需参与（n-of-n）：2人是2/2、3人是3/3、5人是5/5。参与列表和恢复门限均绑定在恢复证明上下文中。不能把“至少两人登记”和“任意两人可恢复”混为一谈。

成功准入后生成独立会话密钥份额与会话指纹、训练模型，打包完整基座及适配器，AES-GCM整体加密。实验实际从密文中解出模型包并重新加载，再通过一次性本地HTTP服务进行768前缀指纹读取，测量WikiText-2 PPL。实验只创建每会话一份模型，尚未创建逐托管方模型副本。

```
.venv/bin/python -m pytest -q
.venv/bin/python run_identity_gate_experiment.py --output work/identity_gate_experiment/new_run --threshold-policy all
```

输出包括五组密码学重复记录及公开证明 `crypto_metrics.json`、训练前登记 `registration_before_training.json`、模型结果 `model_metrics.json`、HTTP响应、完整模型包与密文。五组重复仅针对密码学准入和份额恢复；模型只按首次登记各训练一次。不要把加密实验的重复当成模型独立训练成功率。输出模型、可关联指纹及公开登记仍应依使用情境管理。

这是可信本地Python进程模拟，不是现实身份认证或强制执行的安全边界。预登记承诺和证明不自动证明现实身份；未实现可信人员身份核验、私密认证通道、持久化抗重放、分布式共识或防止绕过本地函数。实验在已验证登记后才执行模型流程；最新入口还在每个阶段检查本门禁签发的准入对象。旧版运行时使用入口代码快照保存在其实验目录，可区分事后新增的防误用检查。
