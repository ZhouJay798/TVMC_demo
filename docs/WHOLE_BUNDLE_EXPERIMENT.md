# 3/3会话 + 逐人密文 + 整体外层加密

五位身份预登记，1、2、3通过会话身份知识证明登记C-E0；生成3/3 Shamir份额和Feldman承诺、份额及身份联合知识证明，注册每个RSA个人公钥，使用身份知识证明与RSA-PSS密钥持有证明绑定。

会话内独立训练U1/U2/U3三个逐人指纹适配器，每份完整模型包分别以独立随机AES-256-GCM数据密钥加密；数据密钥以对应RSA-2048 OAEP/SHA-256公钥封装。对三份密文和RSA封装建立发行方Ed25519签名清单，整体ZIP打包，再以3/3恢复的会话秘密经HKDF派生的AES-GCM密钥加密整包。内容、身份、公钥、会话、周期、副本编号及哈希绑定；发行方公钥必须在包外可信固定。本地记录中的公钥仅为模拟信任锚。

默认在内存构造、加密、解密和验证完整外层包；新脚本可选 `--persist-bundle` 保存加密包。历史实验未写入磁盘以适应有限空间。仅保存加密包哈希、签名清单、公开登记、模型适配器、HTTP响应和指标；会话秘密、份额、个人私钥及完整外层包不保留。因此不能在本次进程退出后对同一个大包重新做密码解密，需重跑生成新的数据；公开复核也不能声称重新验证了未保存的大包字节。

在5组独立随机小载荷试验中测试不足份额接口拒绝和直接插值解密观测、本人解密、跨人私钥、错误会话密钥、外层密文篡改、错误签发方、持会话密钥修改已签名清单及替换个人公钥。完整模型大包仅做一次；三份模型各训练一次。3/3门限在受信本地模型中检查，进程并不代表真实分布式托管方。

测试自然文本768前缀的一次性HTTP批量读取、单输入一次性盒、无指纹对照、明文副本转交对照、PPL；另测试三对模型适配器的50/50有效参数混合。适配器合并采用rank16表示精确平均有效权重更新，属于真实模型头部参数混合；不是全部合谋方法或其他攻击的穷举。

另对原有3/3份额执行一轮刷新及身份重抽，核对份额、身份承诺变化和会话秘密保持，使用前面已验证解开的历史内层密文继续解密，检查模型哈希。历史run1未将刷新后的密钥再次用于解密已释放的完整外层包。当前脚本已补齐：保留完整外层包至刷新及身份轮换后，用恢复的同一密钥再次解开整包，再释放内存；新结果字段为 full_outer_bundle_reopened_after_refresh。

```
.venv/bin/python -m pytest -q
.venv/bin/python run_bundle_experiment.py --output work/bundle_experiment/new_run
.venv/bin/python audit_bundle_experiment.py --run-dir work/bundle_experiment/new_run
```

输出：`crypto_metrics.json`、`model_metrics.json`、训练前登记、签名清单与各次HTTP响应。`audit_bundle_experiment.py` 核对本地信任快照下的预登记身份、份额证明、接收公钥绑定、发行方签名清单及重算HTTP解码；它不能验证未保存的外层密文字节、签发者现实身份或HTTP响应的外部真实性。

三次模型定位不能估计跨训练成功率，单次成功不能证明全面安全。恶意签发方、恶意模型生成方、个人私钥或明文被盗、接收人转交模型及未覆盖的指纹移除/伪造攻击均需额外信任与实验。模型指纹指示登记副本来源，并不证明实际泄漏行为人的身份。

本地 `*.pt` 适配器是未加密的中间文件，基座也在同一工作区；因此实验密文隔离的结论仅针对封装API和密文，并不能限制能直接访问实验工作区的用户。签名清单另外作为公开审计材料保存，相关登记元数据不具备外层包的保密性。部署时需要分别保护生成组件、私钥、明文适配器以及可信签发方公钥。
