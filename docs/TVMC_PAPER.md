## 摘要

前沿模型的权重，以及保护这些权重的密钥，正日益分散在众多托管方之间（多云区域、边缘节点、联盟成员）。标准的秘密共享提供了机密性，却缺乏问责能力：一个出售自身份额的低于阈值的合谋联盟无法被识别；一个被窃取后以 API 形式重新部署的模型也无法被溯源到泄露者。现有的可追溯秘密共享（TSS）在一个假设下追踪一个黑盒重构盒：该盒可被自适应地反复查询——这一假设对于自毁/限速的盒会失效。而模型指纹技术只能追踪重新部署的模型，却忽视了密钥托管。我们提出 **TVMC**，它通过一条单一、可公开裁决的问责链，将一个可追溯—可验证的秘密共享密钥托管层与一个抗合谋的信号域指纹层绑定在一起。我们形式化了一个新的性质——**部署可追溯性（deployment-traceability）**：与经典黑盒 TSS 追踪不同，它追踪的是一个被重新部署的模型，并且即使面对只接受单次查询的盒也能成立。我们给出了一个构造（基于 Feldman/Pedersen 的托管层 + 基于查询的 Tardos 指纹），并在诚实多数与随机预言机设定下证明了其安全性；所依据的鲁棒嵌入假设，其对抗自适应删除/蒸馏攻击的有效性仍是一个经验性问题——我们将其明确界定而非下定论。与底层 VSS 相比，每个份额仅增加一个域元素。我们描述了一个原型设计与评估方法学；实证研究仍在进行中，本版本中所有报告的数据均为示意性占位值。

## 1 引言

前沿模型的权重——以及控制其访问权限的密钥——越来越多地不再存放于单一位置。它们被分散在多云区域、边缘节点和联盟成员之间，既是为了避免单一泄露点，也是为了满足治理约束。阈值秘密共享（threshold secret sharing）使这成为可能：任意 $t$ 个托管方可以共同使用该资产，而少于 $t$ 个托管方则一无所知。

然而，秘密共享提供了机密性，却没有问责能力。一个出售自身份额的低于阈值的合谋联盟无法被识别；一个被窃取、轻微变换后以 API 形式重新部署的模型，也无法被溯源到其泄露所来自的那次会话。具体而言，存在两个问责缺口：(i) **密钥泄露归因**——究竟是哪个托管方泄露了密钥份额；(ii) **部署归因**——被重新部署（可能经过微调/量化/剪枝）的模型源自哪一次会话。这两者通常由互不相交的研究社群分别处理。可追溯秘密共享 [6,7,8,9] 追踪一个对抗性的黑盒重构盒，但其追踪策略假设该盒可被自适应地多次查询，这一假设在自毁或限速的盒面前崩塌 [11]；此外，这些方案都不能追踪一个重新部署的模型。模型指纹 [15,21] 能追踪重新部署的模型，却对最初是谁泄露了密钥只字不提。

我们用 TVMC 同时弥合这两个缺口：它通过一条单一、可公开裁决的问责链，将一个可追溯—可验证的密钥托管层与一个抗合谋的信号域指纹层绑定在一起。密钥层（一个基于 Feldman/Pedersen 的可追溯 VSS）在某一联盟以可验证方式重构或出售份额时提供问责；部署层用**会话级的 Tardos 指纹**为每一个对外发布的模型实例打上标记，因此一个被窃取并重新部署的副本只需通过少量黑盒查询即可被溯源——即便面对只接受单次查询的盒也是如此。一条由 `seed = H(sid ∥ e ∥ {φ_i})` 派生的身份桥（identity bridge）将两条追踪线锁定到同一个参与方集合上；而一个公开的 **Judge（判定者）** 可在无需任何私有验证密钥的情况下裁决任何一种证据。我们形式化了所得的新性质——部署可追溯性，并证明它能经受一次性/限速盒。

**贡献：**

1. 一个托管模型 TVMC，以及一个新安全概念——部署可追溯性（第 3 节形式化）。
2. 一个双层绑定构造——可追溯—可验证密钥托管 + 会话级模型指纹 + 身份桥（第 4 节）。
3. 安全性证明（机密性、可验证性、密钥层/部署层可追溯性、双层不可嫁祸性、绑定一致性、跨周期可追溯性）（第 5 节），其中支撑部署可追溯性的鲁棒嵌入假设被明确陈述。
4. 一个原型设计（第 6 节）与详尽的评估方法学（第 7 节）。开源实现与实证研究正在进行中；本版本报告的是示意性占位值，而非实测结果。

在我们所针对的 AI 资产托管设定下，一句话概括其差异：TVMC 既不需要不可区分混淆（iO），也不需要指数级大小的份额（不同于 [8,9] 的一般访问结构结果，后者解决的是不可比较的问题），并且它用一个诚实多数假设换取了部署可追溯性——这是纯密码学无法提供的保证，也与经典黑盒重构盒追踪不可直接比较。有两个支撑性的局限被前置披露：第 5 节的鲁棒嵌入假设（假设 12），以及资产 $W$ 在一次受控使用会话期间对消费者变为明文这一事实，因此部署层提供的是**事后问责**，而非 $W$ 的持续保密（第 8 节）。

**文章结构。** 第 2 节综述相关工作。第 3 节给出模型与定义。第 4 节给出构造，第 5 节给出安全性分析。第 6、7 节涵盖实现与评估。第 8 节讨论局限，第 9 节总结。

## 2 背景与相关工作

**秘密共享与 VSS。** 阈值秘密共享始于 Shamir [1]。可验证秘密共享（VSS）使各方能够针对恶意的"分发者"（dealer）检验份额：Feldman [2] 使用离散对数承诺（信息论绑定、计算性隐藏，份额大小 $1|s|$），Pedersen [3] 在 DL 假设下实现了信息论隐藏（份额大小 $2|s|$）。两者都在诚实多数设定下运行，并构成阈值密码学与 DKG [5] 的基础；主动秘密共享（proactive secret sharing）[4] 周期性地重新共享以抵抗移动敌手，我们将其用于跨周期追踪。TVMC 的密钥层建立于这些之上，并为每个份额额外增加一个自采样的域元素。

**可追溯秘密共享。** Goyal–Song–Srinivasan [6] 通过对抗性重构盒引入了 TSS；Boneh–Partap–Rotem [7] 给出了高效的阈值构造。Goyal–Jain–Partap [8] 强化了定义，并利用不可区分混淆扩展到一般访问结构；Farràs–Guiot [9] 给出了一个信息论意义下的一般访问结构方案，但要求访问结构被隐藏，且份额呈指数级大小；Dey 等人 [10] 将追踪者分布式化并使验证公开化；Baghery 等人 [11] 将 VSS 与可追溯性结合（TVSS），并指出基于盒的追踪在面对单次查询盒时会失败。这一系列工作有一个共同的局限：追踪的目标是一个可再查询的黑盒重构盒，而没有任何一个能追踪重新部署的模型。我们明确承认其中的重叠：TVMC 的密钥托管层本质上是对 TVSS 式可追溯 VSS（Feldman/Pedersen 承诺、每个参与方自采样的元素、以及重构时与索引绑定的知识证明）的一次重新实例化；我们的新颖之处不在于密钥层，而在于部署层以及将两者绑成一条可裁决链的密码学桥梁。

**模型水印、指纹与抗合谋码。** 所有权验证技术通过后门式或基于查询的指纹 [18]，将隐藏信号嵌入模型权重 [17] 或行为中；基于编码的方案如 iSeal [21] 用纠错码对目标进行编码。抗合谋指纹可追溯到 Boneh–Shaw [14] 与叛徒追踪（traitor tracing）[13]；Tardos 码 [15]（结合 [16] 的对称变体）达到了 $O(c^2\log(N/\varepsilon))$ 的长度，可抵抗 $c$ 个合谋者与栽赃攻击。这些方法能追踪重新部署的模型，却忽视了密钥托管。TVMC 将其部署层复用了这套机制，并将其与密钥层绑定。

**模型提取与水印移除攻击。** 部署层必须经受得住那些会改动被窃模型的敌手。模型窃取/提取 [19] 与移除攻击（微调、剪枝、量化，尤其是蒸馏到一个干净的"学生"模型）已知会削弱乃至抹除模型水印 [20]。这条攻击线直接划定了部署可追溯性所能承诺的边界，并促使我们明确提出鲁棒嵌入假设（假设 12）以及相应的对抗性评估（第 7.5 节）。

**可问责阈值密码学。** 一条平行的研究线使阈值签名/解密具有可问责性，以平衡隐私与可追溯性（例如带主动刷新的可问责阈值签名 [12]）。TVMC 的不同之处在于目标（托管一个大模型资产，而非单次签名操作），以及提供能够经受一次性盒的部署可追溯性。

**定位。** 据我们所知，TVMC 是第一个将密码学密钥追踪与信号域模型指纹绑定进同一条可公开裁决链的 schemes。我们强调，这是一种**不同的**保证，而非严格更强的保证：部署可追溯性用模型指纹替换了黑盒重构盒追踪，二者不可比较。定性的特性对比见表 6（第 7.6 节）；其表注说明了每一列应在何种范围内解读。

## 3 系统模型与安全定义

### 3.1 系统模型与实体

TVMC 保护一个大模型资产 $W$。出于效率考虑，我们并不直接对 $W$ 进行秘密共享：而是用一个认证加密（AEAD）密钥对其进行加密，`ct_W = AEAD.Enc(KDF(K), W)`，其中 $K \in \mathbb{Z}_p$ 是一个高熵标量，我们公开 `ct_W`，而仅共享 $K$。共有四个实体：

- **拥有者/分发者 D**：训练并注册 $W$；运行共享过程、生成追踪材料，并私有持有指纹追踪密钥 `tsk`。
- **托管方 $P_1,\dots,P_n$**：每个持有私有份额 `sh_i` 与追踪凭据 $\varphi_i$；任意 $t$ 个托管方可以发起一次受控使用（解密/推理）会话。
- **追踪者/判定者（Tracer/Judge）**：运行追踪与公开验证；不需要任何私有验证密钥（遵循 [10]）。
- **敌手/买家 A**：试图在不被问责的前提下牟利。

我们假设诚实多数 $n \ge 2t+1$、一个广播信道、以及私有分发者信道（继承自 VSS）。系统按周期 $e = 1,2,\dots$ 运行，并进行主动重新共享（proactive re-sharing）。拥有者在公开会话注册表 `Reg = {(sid, e, P, cm_w)}` 中维护记录，其中码字以承诺（commitment）形式出现；Tardos 解码密钥 `tsk` 保持私有。

### 3.2 敌手模型与三条泄露渠道

敌手 $A$ 静态地腐化一个未授权的子集 $J \subseteq [n]$，$|J| = f < t$（在周期之间可移动）。其三条变现渠道由不同的追踪层处理——这一分离是设计核心，必须前置声明（表 1 概览）。

**表 1：三条泄露渠道及各自负责追踪的层**

| 渠道 | 敌手行为 | 负责层 |
|------|----------|--------|
| (C1) 出售份额 / 服务产生可验证的重构记录 | 密钥层（VerifTrace） |
| (C2) 黑盒 / 一次性盒仅输出结果、不提供证明 | 部署层（DeployTrace） |
| (C3) 重新部署模型将 $W$（可能经过 $T$-变换）作为 API 部署 | 部署层（DeployTrace） |

**备注 1（诚实范围声明）。** 密钥层仅在敌手以可验证方式参与重构（C1）时产生问责，它本质上是通过与身份绑定的知识证明实现的"可问责重构"。纯密码学无法处理 C2/C3（无证明、不可再查询），这正是我们引入信号域部署可追溯性的原因。两层通过第 4.5 节的桥梁被绑定到同一身份。

### 3.3 TVMC 语法

一个 TVMC scheme 是如下元组：
`(Setup, Share, Verify, SessUse, FpEmbed, VerifTrace, DeployTrace, Judge, Refresh)`：

- `Setup(1^λ) → pp`：素数阶群 $G=\langle g\rangle$、$NIZK$ 参数、Tardos 参数 $(\ell, c, \varepsilon_{tr})$、变换类 $T$、哈希 $H$、$KDF$。
- `Share(pp, n, t, K) → ({sh_i}, {φ_i}, π_share, tk, vk)`，其中 `sh_i = (f_i, γ_i)`，`φ_i = (i, c'_i = g^{γ_i})`。
- `Verify(pp, {sh_i}, π_share) → {0,1}`。
- `SessUse(sid, e, {sh_i}_{i∈Q}, F) → (out, π_rec, who)`。
- `FpEmbed(sid, e, P, tsk) → (W^{sid}, cm_w)`。
- `VerifTrace(out, π_rec, tk) → (b, I_key, π_trace)`。
- `DeployTrace_D(Reg, tsk) → (I_dep, π_dep)`（对可疑部署 $D$ 的黑盒访问）。
- `Judge(vk, I, π) → {0,1}`（确定性、公开）。
- `Refresh(e→e+1)`：主动重新共享。

### 3.4 安全定义

令 $\text{negl}(\lambda)$ 为可忽略函数。除了标准正确性（诚实共享 + 诚实会话以压倒性概率恢复 $K$；且一个诚实发布的实例能解码回其会话）之外，我们要求如下性质。

**机密性。**

**定义 2（保密性）。** 对所有 PPT 敌手 $A$、所有 $K_0, K_1$ 以及所有 $\Lambda \subseteq [n]$ 且 $|\Lambda| \le t-1$，
$$\left|\Pr\big[A(pp, π_{share}, \{φ_i\}_{i∈[n]}, \{sh_i\}_{i∈\Lambda}) = 1 \mid K_0\big] - \Pr[\cdots \mid K_1]\right| \le \text{negl}(\lambda),$$
在 DL 假设下成立。交出所有凭据 $φ_i$ 是无害的，因为它们仅用于追踪，且与承载秘密的多项式相互独立。

**可验证性。** 继承自 Feldman/Pedersen：在 DL 假设下，任何通过 `Verify` 的份额都能重构出唯一的 $K$（承诺的绑定性），即使面对恶意的分发者也是如此。该陈述是标准的，故省略。

**密钥层可追溯性（渠道 C1）。**

**定义 3（密钥层可追溯性）。** 若对所有的 PPT $A$ 都有 $\Pr[\text{Exp}^{key}_A(\lambda)=1] \le \text{negl}(\lambda)$，则称方案是密钥层可追溯的，其中 $\text{Exp}^{key}_A(\lambda)$ 为：
1. $A(1^\lambda) → (n,t,J)$，$|J| = f < t$；
2. 挑战者运行 Share，将 $\{sh_i, φ_i\}_{i∈J}$、$π_{share}$ 及所有凭据交给 $A$；
3. $A$ 输出一条记录 $(out, π_{rec})$；
4. 若 $π_{rec}$ 未通过 VerifTrace 的有效性检查，输出 0；
5. $(b, I_{key}, π_{trace}) ← \text{VerifTrace}(out, π_{rec}, tk)$；
6. 当且仅当 $(I_{key} \not\subseteq J \;\lor\; I_{key} = \emptyset \;\lor\; \text{Judge}(vk, I_{key}, π_{trace}) = 0)$ 时输出 1。

**双层不可嫁祸性（non-imputability）。**

**定义 4（不可嫁祸性）。** 对所有 PPT $A$ 与任意诚实目标 $i^*$，给定 $\{sh_i\}_{i≠i^*}$ 与 $\{φ_i\}_{i∈[n]}$，$A$ 输出 $(I, π)$ 满足
$$\Pr[\text{Judge}(vk, I, π) = 1 \;\land\; i^* \in I] \le \text{negl}(\lambda).$$
这必须在两层上都成立：伪造密钥层证明需要提取出 $γ_{i^*}$（NIZK 的知识可靠性 + DL）；伪造一个能解码到某个诚实非参与方的部署层码字，则违反 Tardos 的栽赃可靠性与 $H$ 的抗碰撞性，并由种子绑定所锚定。**时间范围**：对 $P_{i^*}$ 的密钥层不可嫁祸性只维持到 $P_{i^*}$ 首次以 $F=\text{Iden}$ 参与一次重构为止（该操作会公开 $γ_{i^*}$）；此后该保证通过在下一次 Refresh 时重抽 $γ_{i^*}$ 来重建（第 4.6 节）。使用功能性披露 $F \ne \text{Iden}$ 的部署则保持 $γ_{i^*}$ 私有，从而完全避开这一注意事项。

**部署可追溯性（渠道 C2/C3）——新性质。** 我们先固定一个"有用性"谓词与盗版者模型。

**定义 5（$(Q, d, η, τ)$-有用部署）。** 固定输入上的一个基准查询分布 $Q$、一个任务度量 $d(·,·)\in[0,1]$（例如分类器的 top-1 一致率、生成模型的归一化编辑距离/嵌入距离）、一个容差 $η$ 与一个阈值 $τ$。一个部署 $D$ 是有用的，当且仅当
$$\Pr_{x←Q}[d(D(x), W(x)) \le η] \ge τ,$$
即 $D$ 在任务分布的一个 $τ$ 比例上与 $W$ 一致（涵盖通过 $T$-变换——如微调/量化/剪枝/蒸馏——得到的副本）。我们记 $\text{Useful}(D, W, τ)=1$，并将 $(Q,d,η)$ 隐去不写。

**备注 6（盗版者/标记模型）。** 遵循抗合谋追踪的惯例 [15,14]，敌手在其获得的 $c$ 个实例基础上构建 $D$，基于标记假设（marking assumption）：在所有 $A$ 的实例都一致的触发坐标 $k$ 上，$D$ 观察到的符号等于该公共值，误差受变换引起的翻转率 $ρ$ 限制（假设 12）；在它们不一致的坐标上，$D$ 的行为任意。我们并不假设 $D$ 能忠实回答结构化查询（超出该行为统计之外）；并且我们明确承认：某些变换（尤其是蒸馏）可能违反标记假设——这些恰恰是将在第 7.5 节评估的攻击。

**定义 7（$c$-合谋部署可追溯性）。** 若对所有 PPT $A$ 都有 $\Pr[\text{Exp}^{dep}_{A,c}(\lambda)=1] \le \text{negl}(\lambda)$，则称方案是 $c$-合谋部署可追溯的，其中 $\text{Exp}^{dep}_{A,c}(\lambda)$ 为：
1. $A(1^\lambda) → (n,t,J)$，$|J| = f < t$；
2. 挑战者运行 Setup、Share；公开 $ct_W, π_{share}$；将 $\{sh_i, φ_i\}_{i∈J}$ 与所有凭据交给 $A$；$tsk$ 被扣留；
3. $A$ 发起至多 $c$ 次受控使用会话（合谋规模 $c$），获得对应的 $W^{sid}$；Reg 被公开更新；
4. $A$ 输出一个可疑部署 $D$（可为黑盒 / 回答一次后拒绝）；
5. $(I_{dep}, π_{dep}) ← \text{DeployTrace}_D(Reg, tsk)$；
6. 当且仅当 $\text{Useful}(D,W,τ)=1$ 且 $(I_{dep} \cap J = \emptyset \;\lor\; \text{Judge}(vk, I_{dep}, π_{dep}) = 0)$ 时输出 1。

**备注 8。** DeployTrace 仅向 $D$ 发出有限多次指纹验证查询，因此该保证能经受一次性/限速盒——这是对 [11] 中批评的直接回应。它依赖于鲁棒嵌入假设（假设 12），该假设被明确摆出以与第 7 节的实验相匹配。

**绑定一致性（Binding-consistency）。**

**定义 9（绑定一致性）。** 对于任一其参与集合 $P$ 至少包含一个腐败方的会话，任何 PPT $A$ 都无法以不可忽略的概率输出 $(out, π_{rec})$ 与一个部署 $D$，使得 $\text{VerifTrace}→I_{key}$ 与 $\text{DeployTrace}_D→I_{dep}$ 均被 Judge 接受，却二者判定不一致，即 $I_{key} \cap I_{dep} = \emptyset$ 或它们的公共元素落在 $P$ 之外。等价地说：当两层都接受时，它们的交集非空，且标识出同一会话中一个真实的参与方。

**跨周期（主动）可追溯性。**

**定义 10（跨周期可追溯性）。** 在 Refresh 下，一个移动敌手可在每个周期腐化不同的子集 $J_e$，受标准主动上界约束：每个周期 $e$ 都有 $|J_e| < t$（并且，出于保密性，单一周期的 $t$ 个份额永不整体暴露）。对于发生在周期 $e^\star$ 的任意泄露（C1/C2/C3），即便份额与凭据已被刷新，VerifTrace 或 DeployTrace 仍以压倒性概率溯源到 $J_{e^\star}$，且每个周期都保持不可嫁祸性。

**表 2：性质 – 假设 – 所属层 对应关系**

| 性质 | 主要假设 | 所属层 | 渠道 |
|------|----------|--------|------|
| 机密性 | DL + AEAD | — | — |
| 可验证性 | DL（绑定） | 密钥层 | 恶意 D |
| 密钥层可追溯性 | NIZK 可靠性 + DL | 密钥层 | C1 |
| 不可嫁祸性（双层） | NIZK + DL；Tardos 栽赃 + H | 两层 | C1/C2/C3 |
| 部署可追溯性 | Tardos 合谋 + T-鲁棒性 | 部署层 | C2/C3 |
| 绑定一致性 | H 抗碰撞 + Tardos 可靠性 | 桥 | — |
| 跨周期可追溯性 | 主动周期绑定 | 两层 | C1/C2/C3 |

## 4 构造

### 4.1 概览与数据流

TVMC 包含两层与一个桥梁（图 1）。密钥托管层（§4.3）通过 Feldman 式 TVSS 共享 AEAD 密钥 $K$；每一次受控使用会话都需要与索引绑定的 NIZK，从而为 C1 提供问责。部署指纹层（§4.4）用会话级的抗合谋 Tardos 指纹为每个发布的模型实例打标记，因此一个被窃取并重新部署的副本（C2/C3）即使经历 $T$-变换或一次性访问，也能通过黑盒查询被溯源。身份桥（§4.5）由 `seed = H(sid ∥ e ∥ {φ_i}_{i∈P})` 派生出指纹码字，将两层锁定到同一参与集合。

**图 1：TVMC 端到端数据流。** `FpEmbed→"受控使用"` 这一边携带带指纹的实例 $W^{sid}$；种子将两条追踪线绑定到同一参与集合。

```
Share ── Owner ──> 份额 + ct_W
FpEmbed ── Owner ──> 嵌入 + Reg
SessUse ── Custodians ──> 恢复 K、NIZK
Consumer ── 泄露受控使用 ──> 获得 W（C1/C2/C3）
VerifTrace + DeployTrace ── Tracer ──> 公开 ──> Trace Judge
```

### 4.2 构成模块

素数阶群 $G=\langle g\rangle$，$|G|=p$，DL 困难；Feldman 承诺 $g^{(\cdot)}$（可被 Pedersen 替换以获得信息论隐藏，见 §4.7）。带密钥 $\kappa=\text{KDF}(K)$、$K\in\mathbb{Z}_p$ 的认证加密。针对如下关系的 Fiat–Shamir Σ-NIZK（在 ROM 下具有知识可靠性）。Tardos 码 $\text{Tardos}=(\text{Gen},\text{Enc},\text{Dec})$，长度 $\ell=O(c^2\log(N/\varepsilon_{tr}))$，抗合谋且抗栽赃，以查询方式嵌入。通过零份额掩码实现主动重新共享。我们令 $φ_i := (i, c'_i = g^{γ_i})$ 作为一个公开身份承诺，其打开值 $γ_i$ 由 $P_i$ 持有。

### 4.3 密钥托管层

该层由算法 1–3 组成。

**Verify**：每个 $P_i$ 检查 $g^{f_i} = \prod_{j=0}^{t} c_j^{\,i^j}$ 且所有 $c'_k \in G$ 格式正确；超过 $t$ 次投诉则取消某方或 D 的资格（Feldman，外加 $c'_k$ 检查）。

**算法 1 `Share(pp, n, t, K)`（可验证性、机密性）**

```
1: D 采样 f(X) = K + a_1 X + ··· + a_t X^t；令 f_i ← f(i)
2: 对 i ∈ [n]：私下将 f_i 发送给 P_i；公开 c_j = g^{a_j}（j = 0..t，a_0 := K）
3: 对 i ∈ [n]：P_i 采样 γ_i ← Z_p，广播 c'_i = g^{γ_i}，存储 sh_i = (f_i, γ_i)
4: π_share = vk = tk := (c_0, …, c_t, c'_1, …, c'_n)；令 φ_i := (i, c'_i)
5: D 存储 Tardos 主密钥 tsk ← Tardos.Gen(1^λ; ℓ, c, ε_tr)
6: ct_W ← AEAD.Enc(KDF(K), W)；公开 ct_W
7: return ({sh_i}, {φ_i}, π_share, tk, vk)
```

**算法 2 `SessUse(sid, e, {sh_i}_{i∈Q}, F)`（密钥层正确性，C1）**

```
1: 公开计算 y_i = ∏_{j=0}^{t} c_j^{i^j}（= g^{f_i}）  ▷ 由 π_share 与索引 i 得到
2: 对 i ∈ Q：P_i 公布 z_i = F(f_i) 及 NIZK π_i，证明关系
      R_i = {(g, F, z_i, y_i, c'_i; (f_i, γ_i)) : z_i = F(f_i) ∧ y_i = g^{f_i} ∧ c'_i = g^{γ_i}}
   ▷ 若 F = Iden，则 π_i = (f_i, γ_i)，对照 y_i, c'_i 检查（零证明开销）
3: 验证并收集有效集合 V ⊆ Q；设置 n 位字符串 who
4: 若 |V| = 0 则返回 ⊥
5: 否则若 |V| ≥ t+1 则插值出 out = F(K)（或恢复 K 后 AEAD.Dec 得到 W）
6: 否则（0 < |V| < t+1）out = {z_j}_{j∈V}
7: 结束
8: π_rec := (who, {π_j}_{j∈V})；return (out, π_rec)
```

### 4.4 部署指纹层

该层由算法 4 和 5 组成。

**备注 11（粒度诚实性）。** 指纹原生地解析到会话（参与集合 + 消费者 + 周期）。"会话内部究竟是哪一个托管方"通过跨会话交集（合谋）来解析，或归咎于消费者（单会话再分发）；精确的个体级归因需通过与密钥层交叉核对来完成（绑定一致性，定理 21）。算法 5 的交集步骤是一种启发式，而非被证明的归因规则：若 $\bigcap_{sid∈S^*} P_{sid} = \emptyset$（被指控的会话互不相交），DeployTrace 返回并集 $\bigcup_{sid} P_{sid}$，标记为"仅会话级"，并将个体归因推迟到密钥层；在没有密钥层佐证的情况下，它绝不会收窄到单一对象——正是这一点保护了不可嫁祸性。

**算法 3 `VerifTrace(out, π_rec, tk)`（密钥层可追溯性、不可嫁祸性）**

```
1: 解析 π_rec = (who, {π_j})；令 I_key ← ∅
2: 对 who 中标记的每个 j：
3:   y_j ← ∏_{k=0}^{t} c_k^{j^k}
4:   若 NIZK.V((y_j, c'_j, F), π_j) = 1，则 I_key ← I_key ∪ {j}
5: 结束
6: 若 I_key = ∅ 则返回 (0, ∅, 0^n)
7: 结束
8: return (1, I_key, π_trace := {π_j}_{j∈I_key})
```

**算法 4 `FpEmbed(sid, e, P, tsk)`（部署可追溯性、绑定）**

```
1: seed_sid ← H(sid ∥ e ∥ {φ_i}_{i∈P})            ▷ 身份桥
2: w_sid ← Tardos.Enc(tsk, seed_sid) ∈ {0,1}^ℓ   ▷ ℓ = O(c^2 log(N/ε_tr))
3: 取秘密触发集 {x_k}_{k∈[ℓ]}；调优/引导使 W^{sid}(x_k) 编码 w_sid[k]
                                               ▷ 码字须经受变换类 T
4: cm_w ← Com(w_sid; r)；将 (sid, e, P, cm_w) 写入公开 Reg
5: 存储打开值 (w_sid, r)；return (W^{sid}, cm_w)
```

**具体嵌入及其开销。** 我们将算法 4 的基于查询的嵌入实例化如下。触发集 $\{x_k\}_{k∈[ℓ]}$ 是一组由 $\text{PRF}_{tsk}$ 派生的输入，与任务分布 $Q$ 大概率不相交。为写入符号 `w_sid[k]`，我们施加一段简短的低秩（LoRA 风格）适配，将 $W^{sid}$ 在 $x_k$ 上的响应推入两个可解码区间之一（对于 LLM，是两个指定下一词元集之间的间隔；对于分类器，是一个指定标签），同时用一个效用正则项惩罚在 $Q$ 的留出切片上的漂移。其代价是每次发布一个实例做一次简短微调，而非每次查询都做，其开销与效用影响必须被测量（第 7 节）；我们明确地将嵌入开销与效用下降列为开放的经验性风险，而非声称其可忽略。嵌入容量（效用退化前 $\ell$ 能增长到多大）限定了可支持的合谋规模 $c$，是评估的一部分。

### 4.5 身份桥与统一裁决

由于 $w_{sid}$ 由 `seed = H(sid ∥ e ∥ {φ_i}_{i∈P})` 派生，而 $φ_i$ 是密钥层的公开身份承诺，因此 $\text{VerifTrace}→I_{key}$ 与 $\text{DeployTrace}→I_{dep}$ 经由 Reg 中登记的 $P$ 对齐。我们不声称这座桥是一个重量级的新原语：它是对参与集合的一个域分离承诺，其唯一职责是使两层联合不可伪造。具体而言，它带来的绑定性由定义 9 刻画、并由定理 21 证明：一个敌手无法同时呈现一个部署层判定与一个密钥层判定，二者都被接受却指向不相交或非同会话的参与方，因为那样将需要种子上的 $H$-碰撞、对 $cm_w$ 的二次打开，或一次 Tardos 误解码。凭据 $φ_i$ 进入种子，正是为了让同一个公开对象同时锚定 NIZK 陈述（密钥层）与码字身份（部署层）；将 $H$ 替换为可提取承诺还能额外获得在线可提取性，但我们不需要。

`Judge(vk, I, π)` 从公开 vk/Reg 出发、以确定性方式处理两类证据（无需私有验证密钥）：对密钥层证据 $π$，它对每个 $i∈I$ 在 $(y_i, c'_i, F)$ 上重跑 $\text{NIZK.V}$；对部署层证据 $π_{dep}$，它检查 $cm_w$ 的打开值是否与 Reg 一致、被指控 $w^*$ 的指控统计量是否达到阈值，以及由登记的 $P$ 重算的种子是否一致。

**算法 5 `DeployTrace_D(Reg, tsk)`（部署可追溯性，C2/C3）**

```
1: 在 {x_k} 上查询 D 有限多次；软解码得到 wˆ    ▷ O(ℓ) 次查询，与盒无关
2: {w^*} ← Tardos.Dec(tsk, wˆ)                  ▷ c-合谋指控
3: 对每个 w^*：w^* → seed → (sid, e, P)（经由 Reg）
4: S^* ← 被指控的会话集合
5: 若 |S^*| > 1（跨会话，C2），则 I_dep ← ⋂_{sid∈S^*} P_sid
6: 否则（单会话再分发，C3），I_dep ← 该会话的消费者/参与方
7: 结束
8: π_dep := (wˆ, {(w^*, (sid,e,P), cm_w 打开值)})
9: return (I_dep, π_dep)
```

### 4.6 主动刷新（Proactive Refresh）

`Refresh(e→e+1)` 运行零份额重新共享以重新随机化 $f^{(e+1)}$（常数项 $K$ 固定），可选地用新的 $c'_i{}^{(e+1)}$ 重抽 $γ_i{}^{(e+1)}$，并以周期 $e$ 为 Reg 建立索引，同时保留旧记录。由于 $tsk$ 与历史 Reg 持续存在，周期 $e^\star$ 的指纹在刷新后依然可解码；在种子中包含 $e$ 使跨周期的码字相互独立。

### 4.7 变体

(i) **Pedersen-TVSS**：用 Pedersen 承诺替换 Feldman 承诺以获得信息论隐藏（份额大小 $3|s|$）。
(ii) **阈值 tsk**：对 Tardos 主密钥进行秘密共享，使 FpEmbed/DeployTrace 成为阈值协议，消除拥有者的单一追踪点。
(iii) **链上 Judge**：将裁决部署为带有托管方质押/罚没（slashing）的合约，替换拒绝服务时的诚实多数假设。
(iv) **TEE 辅助会话**：在 enclave 内运行"先解密、后嵌入"，以证明"发布前先打指纹"。

### 4.8 正确性与效率

**正确性**：诚实共享 + 诚实会话通过 Feldman 插值以概率 1 恢复 $K$；一个诚实发布的实例的码字在无变换时解码回其会话。
**效率**：每个份额增加一个域元素 $γ_i$（Feldman → $2|s|$，Pedersen → $3|s|$）；密钥层追踪是常量次数的会话验证；部署层追踪是对 $D$ 的 $O(\ell)$ 次黑盒查询，$\ell = O(c^2\log(N/\varepsilon_{tr}))$，与盒的查询预算无关。

## 5 安全性分析

我们陈述支撑部署可追溯性的鲁棒嵌入假设。

**假设 12（$(T,ρ)$-鲁棒嵌入）。** 对任意 $τ$-有用部署 $D$（定义 5），DeployTrace 在触发集上读出的观测向量 $\hat{w}$ 与真实会话码字至多在一个比例 $ρ < ρ^*$ 的符号上不同，其中 $ρ^*$ 是所用 Tardos 解码器的纠错半径。直观地说：只要 $D$ 是有用的，它在功能上就接近于 $W$，从而在触发集上以高于阈值的方式暴露出指纹——"有用 ⇒ 可读"。

**定理 13（机密性）。** 在 DL 与 AEAD 安全下，TVMC 满足定义 2。

**备注 14（范围：$K$ 静态保管 vs $W$ 使用中）。** 定理 13 保护的是静态的密钥 $K$（从而也是 $W$），对抗任何持有所凭据与 $t-1$ 个份额的低于阈值联盟。它并不声称一旦会话重构出 $K$ 后 $W$ 的持续保密性：一次受控使用会话必然向授权消费者暴露 $W$（或 $F(W)$），而 FpEmbed 正是在这一明文实例上运行。因此，部署层提供的是对已发布/被窃 $W$ 的事后问责，而非其持续机密性。可选地，在 TEE 内运行"先解密、后嵌入"步骤（§4.7）可缩小这一暴露窗口。

**定理 15（可验证性）。** 在 DL（承诺绑定）下，TVMC 是可验证的。

**定理 16（密钥层可追溯性与不可嫁祸性）。** 在 NIZK 知识可靠性与 DL 下，TVMC 满足定义 3 与定义 4（密钥层）。

**定理 17（$c$-合谋部署可追溯性）。** 若 Tardos 长度 $\ell = O(c^2\log(N/\varepsilon_{tr}))$，具有 $\varepsilon_{tr}$-合谋与 $\varepsilon_{fr}$-栽赃安全性，Com 是计算绑定的，$H$ 是抗碰撞的，且嵌入是 $(T,ρ)$-鲁棒的（假设 12），则对任意发起至多 $c$ 次会话的 PPT $A$，
$$\Pr[\text{Exp}^{dep}_{A,c}(\lambda)=1] \le \varepsilon_{tr}(\lambda) + \varepsilon_{fr}(\lambda) + \text{Adv}^{cr}_H(\lambda) + \text{Adv}^{bind}_{\text{Com}}(\lambda) \le \text{negl}(\lambda).$$

**证明。** 令 `Win` 为 $A$ 成功的事件：$D$ 是 $τ$-有用的且 $(I_{dep}\cap J=\emptyset \;\lor\; \text{Judge}(vk, I_{dep}, π_{dep})=0)$。我们将 `Win` 拆分为三种失败模式并分别界定。

**(E1) 解码失败。** `Tardos.Dec(tsk, wˆ)` 输出不出任何与 $A$ 所获码字匹配的 $w^*$，故 $S^*=\emptyset$ 且 $I_{dep}=\emptyset$，从而 $I_{dep}\cap J=\emptyset$。构造针对 Tardos 合谋安全性的归约 $B$：它将 $A$ 的 $\le c$ 次会话视为对 Tardos 挑战者的 $c$ 次码字查询（种子经 $H$ 由 FpEmbed 给出；$B$ 持有 $tsk$ 并模拟全部 Share/SessUse/FpEmbed；$tsk$ 从不交给 $A$，符合定义 7）。当 $A$ 输出 $D$ 时，$B$ 利用 $(T,ρ)$-鲁棒性（假设 12）将 $D$ 在触发集上的行为转化为一个符号错误率 $\le ρ < ρ^*$ 的盗版码字 $\hat{w}$，提交给挑战者。由合谋安全性，Dec 至少指控一个真实的参与会话（从而经由 Reg 指控 $J$ 中的某泄露者）；否则 $B$ 攻破了合谋安全性。因此 $\Pr[E1] \le \varepsilon_{tr}$。

**(E2) 指控诚实方。** 某个 $w^*$ 经由 Reg 映射到一个其参与方与 $J$ 不相交的会话（将责任推给诚实方），即 $I_{dep}\cap J=\emptyset$ 却 $\text{Judge}=1$。这正是 Tardos 栽赃安全性所禁止的事件：诚实参与方从未将其码字交给 $A$ 用于拼装 $D$，因此 $\hat{w}$ 指控此类码字的概率 $\le \varepsilon_{fr}$。一个与上述同构的归约 $B$ 将其转化为对某个诚实码字的栽赃。因此 $\Pr[E2] \le \varepsilon_{fr}$。

**(E3) 证据/绑定伪造。** Dec 正确，但 $A$ 仍让 $\text{Judge}=0$ 通过（拒绝合法追踪），或让 $w^*$ 映射到错误会话。Judge 的部署层检查要求 $cm_w$ 的打开值与 Reg 一致、且由登记 $P$ 重算的种子一致（算法 5）。要么 $A$ 找到另一个 $(P',e',sid')\ne(P,e,sid)$ 使得同样的 $H(\cdot)=\text{seed}$（攻破 $H$，概率 $\le \text{Adv}^{cr}_H$），要么它将同一个 $cm_w$ 打开到第二个值（攻破 Com 绑定，概率 $\le \text{Adv}^{bind}_{\text{Com}}$）。因此 $\Pr[E3] \le \text{Adv}^{cr}_H + \text{Adv}^{bind}_{\text{Com}}$。

由并集界，$\Pr[\text{Win}] \le \Pr[E1]+\Pr[E2]+\Pr[E3]$，即得所证。

**备注 18（为何一次性盒不构成威胁）。** 整个归约只用了 DeployTrace 第 1 步的 $O(\ell)$ 次指纹验证查询，这些查询取自一个有用的 $D$ 无法拒绝（否则便无用）的合法任务输入。这从根本上不同于"观察跳跃"式追踪 [7,8]——后者需要一个可自适应再查询的盒；因此该保证对自毁/限速盒成立，从而闭合了 [11] 中的批评循环。

**备注 19（起支撑作用的假设，直白说明）。** 定理 17 在假设 12 下归约为 Tardos 安全性。该假设做了实在的工作：将 $D$ 在触发集上的行为转化为低错误盗版码字的步骤，预设了标记模型能经受变换 $T$。对于温和变换（微调、量化、剪枝）这是合理的，并在第 7.3 节测试；对于蒸馏到一个全新学生模型或激进的输入侧过滤，该假设可能失效，此时部署可追溯性不再被保证。因此我们不声称对任意有用 $D$ 的无条件追踪；我们只对假设 12 经实证验证的 $T$ 作出该声称，并将这一边界视为评估目标（第 7.5 节），而非既成结论。

**备注 20（多个发布实例）。** 每个会话在（大概率与 $Q$ 不相交的）PRF 触发集上嵌入一个独立码字 $w_{sid}$，并由 $cm_w$ 隐藏。发布多个实例不会泄露 $K$ 或任何份额（嵌入作用于会话中已暴露的明文 $W$，而非 $\{sh_i\}$），唯一的跨实例信息正是合谋上界 $c$ 已在 $\ell$ 中计入的部分。然而，嵌入容量限制了单一 $W$ 在效用退化前能承载多少个独立码字；这限制了 $c$，并在第 7 节测量。

**定理 21（绑定一致性）。** 在 $H$ 抗碰撞与 Tardos 解码可靠性下，TVMC 满足定义 9。（证明概要：一对被接受却不相交的判定，必然迫使发生 $H$ 对种子的碰撞，或对码字的误解码；归约到这两个假设。）

**定理 22（跨周期可追溯性）。** 在主动周期绑定重新共享与以周期索引的 Reg 下，TVMC 满足定义 10。（证明概要：带周期标记的种子使跨周期码字相互独立；持续的 $tsk$、Reg 使过往指纹保持可解码；对每个周期套用定理 16 与 17。）

## 6 实现

### 6.1 原型概览与代码结构

本节描述预期的原型架构；第 7 节的实现与测量仍在进行中，我们报告的是设计与方法学，而非一个成品。原型用 Rust 编写，以获得内存安全性与成熟的密码学栈，分为三个 crate：`tvmc-core`（密钥托管层）、`tvmc-fp`（指纹层）、`tvmc-bridge`（身份桥、注册表、Judge）。模型侧的嵌入/解码通过 PyO3 绑定暴露给 PyTorch/HuggingFace。表 3 将第 4 节每个算法映射到其实现单元与原语。

**表 3：算法—实现映射**

| 算法 | 模块 | 原语 |
|------|------|------|
| Share/Verify | tvmc-core | Feldman/Pedersen 承诺；$\mathbb{Z}_p$ 多项式 |
| SessUse/VerifTrace | tvmc-core | Fiat–Shamir Σ（Chaum–Pedersen）/ Groth16 |
| FpEmbed/DeployTrace | tvmc-fp | Tardos 码；基于查询的嵌入 |
| bridge, Reg, Judge | tvmc-bridge | $H$（SHA-256/Poseidon）；Merkle 日志 |
| Refresh | tvmc-core | 零份额重新共享 |

### 6.2 密钥托管层

提供两种群后端：(a) ristretto255（curve25519-dalek），用于无配对设定与高效 Σ-证明；(b) BLS12-381（blstrs/arkworks），用于与 BLS 阈值签名/DKG 集成。我们使用 Feldman 承诺 $c_j=g^{a_j}$ 与身份承诺 $c'_i=g^{γ_i}$。关系 $R_i$ 为 $z_i=F(f_i)\land y_i=g^{f_i}\land c'_i=g^{γ_i}$ 的合取：对 $F=\text{Iden}$，$π_i$ 是打开值 $(f_i,γ_i)$，以零证明开销对照 $y_i,c'_i$ 检查；对离散对数型 $F$（如 ElGamal 部分解密 $z_i=c^{f_i}$），我们使用 AND 组合的 Chaum–Pedersen/Schnorr 证明加 Fiat–Shamir（挑战 $=H(\text{transcript})$），大小为 $O(1)$ 个群元素与标量；对一般 $F$，我们用 Groth16 同时证明 $F$ 的电路与知识，以 setup/prover 开销换取通用性。资产 $W$ 用 XChaCha20-Poly1305（或 AES-256-GCM）封装于 $\kappa=\text{HKDF-SHA256}(K)$ 之下；高熵 $K$ 确保公开值 $g^K$ 不泄露关于 $K$ 的任何信息。

### 6.3 部署指纹层

Tardos 码字使用经典有偏采样（$p_k$ 取自截断 Beta(1/2, 1/2)），长度
$$\ell = \left\lceil C\, c^2 \ln(N/\varepsilon_{tr}) \right\rceil,$$
其中 $C$ 为经典（或改进的 Škorić）常数，$N$ 上界会话数。嵌入基于查询：触发集 $x_k=\text{PRF}_{tsk}(k)$ 由密钥派生的秘密输入构成，发布的实例被轻微微调/引导，使 $W^{sid}(x_k)$ 在一个可解码统计量上编码 $w_{sid}[k]$（如基于编码的指纹 [21] 中的 RS 编码目标，此处编码 Tardos 符号；对 LLM 为触发提示处的下一词元分布；对视觉模型为触发输入处的 logits）。鲁棒性（假设 12）通过每符号冗余加软判决投票获得，可容忍由微调/量化/剪枝引起的翻转率 $ρ < ρ^*$。承诺 $cm_w$ 用 Pedersen（用于零知识打开）或基于哈希（更短，ROM 下）。

### 6.4 身份桥与公开注册表

`seed = H(sid ∥ e ∥ {φ_i})` 使用 SHA-256，当 Judge 链上运行时切换为 SNARK 友好的 Poseidon。Reg 是一个只追加、Merkle 化的日志，因此任何人都能用 $O(\log)$ 的成员证明公开验证某条 $(sid,e,P,cm_w)$ 已被登记——这正是公开验证的操作落点。链上 Judge 变体是一个 Solidity 合约：密钥层证据通过 Schnorr/Chaum–Pedersen（BN254 预编译或链下验证-再提交）验证；部署层证据检查 $cm_w$ 的打开值、指控统计量阈值与种子一致性，然后触发质押罚没。

### 6.5 主动刷新

零份额重新共享：各方共享常数项为 0、次数 $t$ 的随机多项式，在本地将其加到 $f$ 与 $c_j$ 上，并可选重抽 $γ_i$。Reg 以周期 $e$ 索引；旧记录与 $tsk$ 持续存在，支持跨周期追踪（定理 22）。

### 6.6 工程优化

我们用 Pippenger 多标量乘法预计算 $y_i=\prod_j c_j^{i^j}$；通过随机线性组合批量验证 $|V|$ 个 Schnorr 证明；当 $F$ 为同态时聚合为单个 $π_{rec}$（§4.3 的紧凑选项）；使用常数时间标量算术（curve25519-dalek）抵御旁路信道，并对 $tsk$ 与 $γ_i$ 清零。可选地，SessUse 的"先解密、后嵌入"步骤运行于 SGX/TDX enclave 内，以证明"发布前先打指纹"。

## 8 讨论与局限

**信任与部署假设。** TVMC 以诚实多数（$n \ge 2t+1$）换取协同恢复与追踪；腐败方可能拒绝参与 SessUse，降低可用性。两种缓解适用：通过 Refresh 重新分发，以及带质押/罚没的链上 Judge（§4.7），它将拒绝/不当行为转化为可罚没的经济代价，削弱了对诚实多数的硬性依赖。追踪密钥 $tsk$ 由拥有者持有——即最有动机保护该资产的一方；阈值 $tsk$ 变体将 FpEmbed/DeployTrace 变成阈值协议，以移除这一单点。

**部署可追溯性的边界。** 部署层安全性（定理 17）建立在 $(T,ρ)$-鲁棒嵌入假设（假设 12）之上：有用 ⇒ 可读。它在常规微调/量化/剪枝下得到经验支持（§7.3），但有其天花板：敌手只能通过将模型推入"无用"区间（例如蒸馏到弱得多的学生模型、对抗性覆盖）来抹除指纹——而此时被窃资产已丧失价值。我们如实声明：对极端变换的鲁棒性是经验性的、且依赖模型/任务；并且其原生粒度是会话级；精确的个体级归因需要与密钥层交叉核对（定理 21）。

**不可嫁祸性的时间范围。** 一旦 $γ_i$ 以 $F=\text{Iden}$ 参与了一次重构，它就变为公开，此后密钥层不可嫁祸性不再保护该方（"直到首次诚实揭示"）。缓解：坚持在部署中使用功能性披露 $F\ne \text{Iden}$（例如阈值解密仅揭示 $c^{f_i}$）以保持 $γ_i$ 私有，或经由 Refresh 在每个周期重抽 $γ_i$。

**密码学假设与 ROM。** 安全性建立在 DL、承诺绑定/隐藏、NIZK 知识可靠性，以及经 Fiat–Shamir 的随机预言机模型之上；一般 $F$ 的 Groth16 实例化需要一个可信 setup（可用透明 SNARK 替换以消除 setup）。Tardos 层是信息论意义的，不增加计算假设。

**后量子路径。** AEAD 层已经是后量子的；需要替换的是 DL 承诺与 Σ/SNARK，对此基于格的承诺与格 NIZK 是候选（代价是更大的证明与份额）。由于 Tardos 层与协议骨架与群结构解耦，迁移是模块化的；我们留待未来工作。

**运维考量。** SessUse 与追踪本质上是一次性的；长期运行部署依赖 Refresh。注册表 Reg 单调增长，通过 Merkle 化加定期归档保持可控。TEE 辅助会话将信任根从"诚实发布者"转移到硬件，值得单独做一次旁路信道评估。

**伦理与双重用途。** 可追溯性可能被滥用来监视合法用户，且指纹由发布给消费者的模型实例承载，引发消费者侧隐私担忧。缓解：只有拥有者能解码（$tsk$ 永不公开）；Reg 与 Judge 公开且可审计以约束追踪权力；治理流程应界定何时可调用 DeployTrace。我们建议将追踪触发条件编码进一份部署策略，而非留给任何一方自行裁量。

**通用性。** TVMC 并非专属于模型权重：任何高价值的秘密共享资产（流式 DRM 密钥、阈值签名密钥）都适用同一"密钥追踪 × 指纹追踪"双层范式。将其与一般访问结构的 TSS（沿 [8,9] 的精神）结合，是自然的下一步。

## 9 结论

我们提出了 TVMC，它通过一条单一、可公开裁决的问责链，将一个可追溯—可验证的密钥托管层与一个抗合谋的信号域指纹层绑定在一起，并形式化了部署可追溯性——这一保证旨在追踪一个被窃取、重新部署的模型，并且在一个明确陈述的鲁棒嵌入假设下，能够在黑盒重构盒追踪所不能生存的单次查询与限速盒面前存活。我们强调，这是一种**不同的**而非严格更强的保证，且它是有条件的——其所依据的假设在蒸馏/提取攻击下的有效性仍待经验确证。该构造不需要 iO、不需要指数级份额，较底层 VSS 每个份额仅增加一个域元素，并支持公开验证与主动刷新。在第 7 节所述的实证研究完成之前，我们将"把密码学密钥追踪与模型指纹绑定"视为一种面向高价值 AI 资产问责制的有前景范式。未来方向包括：验证并收紧鲁棒嵌入假设、一个后量子实例化（格承诺与 NIZK）、一个完全阈值化的追踪密钥，以及对一般访问结构的扩展。

## 附录 A 延迟的证明与协议细节

### A.1 定理 13（机密性）的证明

**证明。** 敌手的视图为 $(pp, π_{share}, \{φ_i\}_{i∈[n]}, \{sh_i\}_{i∈\Lambda})$（其中 $|\Lambda|\le t-1$），以及公开的 $ct_W = \text{AEAD.Enc(KDF(K), W)}$。凭据 $φ_i=(i,g^{γ_i})$ 是独立采样的 $γ_i$ 的函数，且与 $K$ 及承载秘密的多项式 $f$ 统计独立；它们无需 $K$ 即可被模拟。剩余视图 $(\{c_j\}_{j=0}^{t}, \{f_i\}_{i∈\Lambda})$ 恰好是 Feldman VSS 在 $t-1$ 个份额上的视图。由 DL 下的 Feldman 隐藏性，该视图在计算上与 $K$ 独立：任何在 $K_0,K_1$ 间具优势 $\epsilon$ 的区分器都能给出优势 $\epsilon-\text{negl}(\lambda)$ 的 DL 区分器，因为唯一依赖 $K$ 的公开值是 $c_0=g^K$ 且 $K$ 高熵。最后，用均匀密钥替换 $\text{KDF}(K)$（PRF/KDF 安全）并援引 AEAD 语义安全性，使 $ct_W$ 与 $W$ 独立。一个从（凭据模拟）→（Feldman 隐藏）→（KDF）→（AEAD）的标准混合论证，将区分优势界定为 $\text{Adv}^{dl}+\text{Adv}^{kdf}+\text{Adv}^{aead} \le \text{negl}(\lambda)$，与定义 2 吻合。

### A.2 定理 15（可验证性）的证明

**证明。** 承诺 $(c_0,\dots,c_t)$ 在指数上定义了一个唯一的 $t$ 次多项式 $f$。一个份额 $(f_i,γ_i)$ 通过 Verify 当且仅当 $g^{f_i}=\prod_{j=0}^{t} c_j^{\,i^j}$，即 $f_i=f(i)$；附加检查 $c'_i\in G$ 确保每个凭据可打开。因此任意 $t+1$ 个通过验证的份额都插值出相同的常数项 $K=f(0)$，重构因而良定义且唯一。一个使两个不同秘密都通过的恶意分发者，将导致对某个 $c_j$ 的两次打开，与 $g^{(\cdot)}$ 在 DL 下的绑定性矛盾。故除概率 $\text{Adv}^{bind}\le \text{negl}(\lambda)$ 外，经验证的份额重构出唯一的 $K$。

### A.3 定理 16（密钥层可追溯性与不可嫁祸性）的证明

**证明。可追溯性（定义 3）。** 设 $A$ 仅持有 $\{sh_i,φ_i\}_{i∈J}$ 与所有凭据，输出一条通过 VerifTrace 有效性检查的记录 $(out,π_{rec})$。则 $π_{rec}=(who,\{π_j\})$ 至少包含一个对关系 $R_j$ 中陈述 $(y_j,c'_j,F)$ 接受的 NIZK $π_j$，故 $I_{key}\ne\emptyset$。对任意 $j\notin J$，一个被接受的 $π_j$ 由 NIZK 的知识可靠性暗示一个提取器输出见证 $(f_j,γ_j)$；但 $A$ 从未收到 $γ_j$（仅有 $c'_j=g^{γ_j}$ 公开），故提取 $γ_j$ 即求解 DL。因此除概率 $\text{Adv}^{ks}+\text{Adv}^{dl}$ 外，每个被追踪的索引都落在 $J$ 中，即 $\emptyset\ne I_{key}\subseteq J$。由于 Judge 在 $π_{trace}=\{π_j\}_{j∈I_{key}}$ 上重跑同一 NIZK 验证，它接受。故 $\text{Exp}^{key}_A$ 输出 1 的概率至多 $\text{Adv}^{ks}+\text{Adv}^{dl}\le \text{negl}(\lambda)$。

**不可嫁祸性（定义 4，密钥层）。** 我们构造针对 DL 的 $B$。在挑战 $u^*=g^x$ 上，$B$ 运行 $A$，由后者确定 $(n,t,i^*,K)$。$B$ 采样多项式 $f$ 并计算 $\{c_j\}$，令 $c'_{i^*}=u^*$ 而对于 $i\ne i^*$，$c'_i:=g^{γ_i}$（$γ_i$ 已知）；它将所有份额 $\{sh_i\}_{i\ne i^*}$ 与所有凭据交给 $A$（注意 $sh_{i^*}$ 被扣留，符合游戏设定）。模拟是完美的。若 $A$ 输出 $(I,π)$ 满足 $\text{Judge}=1$ 且 $i^*\in I$，则 $π$ 包含对 $(y_{i^*},c'_{i^*},F)$ 接受的一个 NIZK；知识提取器给出 $(f_{i^*},γ_{i^*})$ 其中 $γ_{i^*}=x$，故 $B$ 输出 $x$ 并求解 DL。因此 $\text{Adv}^{NI}\le \text{Adv}^{ks}+\text{Adv}^{dl}\le \text{negl}(\lambda)$。

### A.4 定理 21（绑定一致性）的证明

**证明。** 设某 PPT $A$ 输出一个会话记录与一个部署 $D$，使得 $\text{VerifTrace}→I_{key}$ 与 $\text{DeployTrace}_D→I_{dep}$ 都被 Judge 接受，却 $I_{key}\cap I_{dep}=\emptyset$。部署证据 $π_{dep}$ 含一个被指控码字 $w^*$、其 Reg 条目 $(sid,e,P)$ 与一个 $cm_w$ 打开值；Judge 要求该打开值与 Reg 一致，且由登记 $P$ 重算的 $\text{seed}=H(sid∥e∥\{φ_i\}_{i∈P})$ 与码字一致。密钥证据经接受 NIZK 将 $I_{key}$ 钉在索引上。两者一致却集合不相交，必然迫使以下之一：(i) 登记的 $P$ 与实际生成 $w^*$ 的集合不同、却哈希到相同种子——一次 $H$-碰撞，由 $\text{Adv}^{cr}_H$ 界定；(ii) $cm_w$ 被打开到第二个码字——一次绑定破坏，由 $\text{Adv}^{bind}_{\text{Com}}$ 界定；(iii) $\text{Tardos.Dec}$ 将 $w^*$ 误解码到无关会话，由解码器可靠性 $\varepsilon_{dec}$ 界定。故该事件概率至多 $\text{Adv}^{cr}_H+\text{Adv}^{bind}_{\text{Com}}+\varepsilon_{dec}\le \text{negl}(\lambda)$。

### A.5 定理 22（跨周期可追溯性）的证明

**证明。** 固定泄露周期 $e^\star$。种子包含周期，故跨周期码字由独立的 $\text{Tardos.Enc}$ 输入派生、相互独立；因此来自周期 $e^\star$ 的指纹不会被其他周期的码字混淆。由于 $tsk$ 与以周期索引的 Reg 在 Refresh 后持续存在，周期 $e^\star$ 的码字在刷新后仍可解码，故定理 17 逐字适用于周期 $e^\star$（部署实验以周期-$e^\star$ 注册表重跑）。对密钥层，每周期凭据 $c'_i{}^{(e)}=g^{γ_i{}^{(e)}}$ 使定理 16 在每个周期内成立；零份额重新共享（算法 6）保持常数项 $K$，且作为对一个全新随机掩码多项式的标准主动重新共享，保持对抗每周期腐化 $|J_e|<t$ 的移动敌手的保密性（定理 13）。将每周期的密钥层与部署层保证结合，即得到带每周期不可嫁祸性的跨周期可追溯性。

### A.6 主动刷新伪代码

**算法 6 `Refresh(e → e+1)`（跨周期可追溯性）**

```
1: 对每个 P_i：采样次数为 t、δ_i(0)=0 的 δ_i(X)；广播其系数的 g^{δ_i,j}
2: 每个 P_k 验证 δ_i 承诺；令 ∆(X) = Σ_i δ_i(X)（仅有效贡献者）
3: f^{(e+1)}(X) ← f^{(e)}(X) + ∆(X)；f_k^{(e+1)} ← f^{(e+1)}(k)；相应更新 c_j   ▷ f(0)=K 不变
4: （可选）每个 P_i 重抽 γ_i^{(e+1)}，广播 c'_i^{(e+1)} = g^{γ_i^{(e+1)}}
5: 以周期 e+1 为 Reg 建立索引；保留所有先前记录与 tsk
```

### A.7 Tardos 参数推导

我们用对称 Tardos 方案 [15] 实例化 Tardos。对 $N$ 个码字、合谋上界 $c$、目标错误 $\varepsilon_{tr}$，设定码长
$$\ell = \left\lceil C\,c^2 \ln(N/\varepsilon_{tr}) \right\rceil,$$
偏置变量 $p_k$ 取自截断 Beta(1/2, 1/2)。对观测（软解码）字 $\hat{w}$，每用户指控得分 $S_u = \sum_{k=1}^{\ell} U(\hat{w}_k, w_{u,k}, p_k)$ 使用标准 Tardos 权重
$$U(1,1,p)=\sqrt{(1-p)/p},\quad U(1,0,p)=-\sqrt{p/(1-p)}$$
（及对称情形）。当且仅当 $S_u \ge Z$（阈值 $Z=\Theta(\sqrt{c\ln(N/\varepsilon_{tr})})$）时，该用户被指控。Tardos 分析保证：在来自 $T$-变换的符号翻转率低于解码器半径 $ρ^*$ 的前提下（假设 12），合谋可靠性（一个真实合谋者被指控）错误 $\le \varepsilon_{tr}$，栽赃可靠性（不误告无辜者）错误 $\le \varepsilon_{fr}$。每符号冗余 $r$（对 $r$ 个触发器取多数）将有效翻转率从 $ρ$ 降至 $\sum_{i>r/2}^{r} \binom{r}{i} ρ_0^i (1-ρ_0)^{r-i}$，我们将其设在 $ρ^*$ 之下。
