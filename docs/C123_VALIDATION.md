# C1/C2/C3：逐人副本交付与追踪验证

五位托管方预登记身份，实际登记参与人数至少为2，每会话按参与人数采用 n/n。本轮选择1、2、3：三个独立指纹副本、三把随机AES数据密钥、三个接收人的RSA公钥封装。内层密文及封装和发行方签名清单组成一个ZIP，再用3/3恢复的会话秘密经HKDF派生的密钥对整体AES-GCM加密。

## C1：出售份额或服务重构记录

新增 `tvmc/reconstruction.py`：为每次重构生成随机请求号，份额与身份联合知识证明绑定该请求、会话、公开承诺快照、外层密文哈希及签名清单哈希。通过所有参与方的验证并恢复密钥后，服务签名生成回执。公开复核固定服务公钥、请求上下文、完整参与名单及全部知识证明，支持已消费请求号集合防重放。回执不记录秘密份额或个人私钥。

该原型在单一可信进程模拟参与方，调用方模拟每位托管方生成知识证明并传入 `reconstruct`，由其校验；真实部署需要托管方本地生成证明、私密认证通道和服务端持久防重放状态。回执的执行语义依赖受信服务，证明本身只说明秘密知识，不能独立证明执行。离线私自重构不保证留下回执。`run_c1_offline_control.py` 另做5组独立小载荷试验，绕过恢复/记录接口直接插值，再使用各自个人私钥解开载荷；明确检验无回执的离线恢复边界。

将回执参与集合与已验证签名清单的副本接收人及指纹登记匹配：得到“该参与集合授权的会话中，泄漏样本命中给某托管方的副本”。不能将全体重构参与者都定为泄漏者，也不能由此证明本人实施出售。

## C2：不提供证明的一次性黑盒

每个新端点仅接受一次HTTP请求，第二次请求应为409。分别测试：

- 768自然文本前缀批量输入，返回0/1下一词元分数差；客户端仅使用HTTP输出和预登记码本解码，无服务端证明。
- 单输入、单分数的严格一次性接口，256位协议证据不足。
- 相同768前缀仅返回真实不受限贪心下一词元文本，不暴露分数；非0/1词元视为擦除，每三项至少两项一致才形成一位。该实验不代表所有文本指纹方法。

## C3：重新部署及变换

完整模型包真实解密、重新加载后启动新HTTP服务，测试原始副本定位和PPL。附加实验对本轮新训练的三个适配器逐一测试：将有效更新合并进输出头、对更新矩阵分组8位量化后反量化（浮点推理）、剪掉更新矩阵绝对值最小的50%元素、完全移除更新。后三项只针对两行输出头指纹更新，不是整个模型的量化/剪枝。合并复制输出层，不改动与之共享的基座词嵌入。

完整训练脚本另外运行三对50/50有效更新混合及复制U1交由标记为U2的服务返回结果。多源命中应保留全部来源，不能强行选单人。当前交付包含未修改的基座和独立适配器，接收人能直接忽略适配器；因此“移除更新”是现实可实施的简单绕过，不只是抽象攻击。移除指纹是必要的失败边界对照；若仍有较好PPL但无命中，应报告当前方法不能抵抗该变换。

本轮每副本只重新训练一次；5次独立密码随机性试验不能视为5轮模型训练。未经检验的蒸馏、全模型压缩、指纹伪造、恶意发行方与接口规避不在通过范围内。

## 复现

```bash
.venv/bin/python -m pytest -q
.venv/bin/python run_bundle_experiment.py --output work/bundle_experiment/NEW_RUN
.venv/bin/python audit_bundle_experiment.py --run-dir work/bundle_experiment/NEW_RUN
.venv/bin/python run_c123_validation.py --run-dir work/bundle_experiment/NEW_RUN
.venv/bin/python run_c1_offline_control.py --run-dir work/bundle_experiment/NEW_RUN
.venv/bin/python report_c123.py --run-dir work/bundle_experiment/NEW_RUN
```

结果保存在同一目录的 `crypto_metrics.json`、`model_metrics.json`、`reconstruction_receipt.json`、`c123_metrics.json` 和各HTTP响应中。本轮历史实验的完整外层包因空间限制只保留在内存，刷新并轮换身份后再次解密同一完整外层包再释放；事后公开审计只能复核保留的记录，不能重验未保存的密文。现在运行脚本可选 `--persist-bundle` 将新生成的外层密文保存为 `outer_bundle.aesgcm`，但模拟身份秘密、份额、会话密钥和个人私钥不持久保存，进程退出后仍不能仅凭密文恢复模型；这不构成真实交付服务。发行方与服务公钥为本地可信快照模拟，非现实身份认证。代码和中间明文同在本地工作区，不能作为实际设备隔离证明。
