# 范围和限制

项目目标是按新版流程实际跑通，不承诺证明每个参与者都可信或抵抗所有攻击。

- 本地 5 个角色共享进程；密钥独立但没有主机隔离。Python 无法保证秘密安全擦除。
- DKG 实现 Pedersen 份额验证和 Feldman 提取，遇到错误直接中止；未实现恶意网络下投诉剔除后的持续运行。
- TDH2 根据 Shoup–Gennaro 公式实现混合封装，采用现有 RFC3526 2048 位群，不是论文 ristretto255，约为 112 位安全级别；本项目代码未经过独立密码审计，不能直接套用论文性能/安全参数。公式核对来源：smartcontractkit/tdh2，修订 `70e716112dd3e3d0f84fb0651f69a2b671e3e37b`。
- HPKE 已用 CFRG 官方 RFC9180 向量验证 X25519/HKDF-SHA256/AES-256-GCM Base 模式首消息。此实现只支持这一组合和单消息。
- 真实模型是从 Q4_1 解量化的 SmolLM2-135M-Instruct。实验采用 128 位归因、16 位筛查，三个副本；不声称复现论文 GPT-2 或 100 副本、2048 位目标配置。
- 模型能力只在单份自然语料的分离区间评估；短程业务训练和小样本下一词指标不能代表真实医院/金融等任务。
- 当前探针抽样、位置分配和 token 对选择使用固定演示种子以便流程复现，不具备部署所需的秘密不可预测性；真实权利保护需改用保密随机种子并保持探针秘密。
- 当前真实模型读出使用 logit 差；只返回自由生成文本、不给概率的接口尚未接入。
- 无偏测试码字的数量有限，统一载体增益仅作工程校准。实际副本不会按码字难易重新抽样；若正式副本未通过，报告失败。
- 截断扫描采用固定 rank 网格，不假设误差必然单调。公开基座复位/截断可能保留能力而删除指纹，结果不能隐藏。
- INT8 对照是量化后解量化的数值测试，非真实 INT8 推理内核；结构化剪枝是 MLP 通道置零，未缩小张量维度。
- 全参微调只跑短程诊断，不代表收敛后的业务微调鲁棒性；未宣称解决蒸馏或主动去指纹。
- 文件取证的模型会实际重跑；API 取证为本地 HTTPS 服务，TLS 使用实验中固定的证书哈希。签名取证成员仍是假设中的诚实角色，不能证明任意远端模型不可替换。
- 日志包含持久化哈希链、Merkle 包含性、独立角色签名的树头；历史一致性使用完整前缀复核而非紧凑 CT 证明。见证者在同一主机上，不是独立第三方。
- 服务日志记录连接来源地址及请求中声明的取证者编号；后者不是经过双向 TLS 认证的客户端机构身份。
- 申辩实现提供完整哈希链片段，隐私保护不等于论文理想的最小披露。高度改写而仍保持指纹的请求可能逃过 MinHash 匹配。
- 单次评分与重放限制在当前实验会话中生效。没有提供可恢复的长期密钥库、多进程数据库并发或线上管理后台。
- 份额刷新提供基础函数和测试；完整成员变更、身份轮换、跨版本补丁系统尚未接入主 CLI。重发应使用原密文，不重新生成同谱系载体。
- L3 可信硬件未实现。不能用一个 Python 对象冒充 enclave。

上述限制不影响本地演示“真实副本发行→多人批准→个人解封→文件/API 指纹追踪→申辩核对”的主流程，但限制它能够支持的安全结论。
