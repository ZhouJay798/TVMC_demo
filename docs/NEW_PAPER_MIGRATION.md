## 主实验过程

1. 五个成员各自生成身份及接收密钥，登记绑定并完成接收私钥持有挑战。
2. 模拟两次联合密钥生成，得到释放密钥和码本密钥。不会计算并返回完整联盟私钥。
3. 固定偏置、阈值、读码说明的承诺，再生成合成码字与加密码本。码本哈希被发行者清单签名绑定。
4. 在**合成向量**上使用共享单位载体构造三份副本；无单独 LoRA 训练。该向量实验只测试协议和评分，不代表语言模型嵌入。
5. 每份副本使用独立随机数据密钥，分块认证加密；内层 HPKE 只给对应接收人；外层实验胶囊由 3/5 门限解封。
6. U1/U2/U3 分别签署请求，均由不含接收人的三名成员批准，验证“批准权不等于接收权”。
7. 三份副本都解密并比较原始字节；签署回执。
8. 对已交付 U1 文件先承诺哈希，读出合成码字，在加密码本上评分，只解密分数，并比较明文计算结果。
9. 将参数、密文、证明、签名和文件交给不使用私钥的复核函数，核对得分、接收人映射、日志次序和一次性使用。
10. 可选地将现有真实模型归档重新封装交付，仅检验字节完整性；不重新训练或宣称新指纹鲁棒性。

## 与论文的差异——不能省略

- **DKG**：本地模拟 Feldman 联合贡献；不是论文 Pedersen VSS + 完整恶意安全 DKG。没有认证网络、投诉剔除、抗偏置证明，也不具备进程隔离。Python 大整数不保证常数时间。
- **外层**：带标签与临时密钥知识证明的 DH-KEM/AEAD 原型，**不是 TDH2**，不声称拥有论文的 CCA 安全证明。正式替换需经过审查的实现。
- **群与身份**：沿用仓库 2048 位 RFC3526 群，身份用 Ed25519；不是论文 ristretto255/Schnorr 配置，不能引用论文的 128 位安全参数和性能结果。
- **指纹**：合成共享载体向量用于协议验收；尚未实现 GPT-2 的闭式载体编辑、业务更新合并、token 对选取、版本截断扫描、两阶段同源筛查。真实模型包沿用旧指纹。
- **码本与参数**：实验固定种子生成测试码字；必须换成秘密随机生产码字。发行者/测试进程仍保有测试资料；未实现真正秘密擦除或探针门限托管。没有把 L2 发行者信任移除。
- **证据**：实现文件取证和公开重算；没有 API 多成员独立取证、转发申辩、相似查询匹配或在线端点真实性保障。
- **日志**：本地哈希链与调用方固定的检查点。没有 Merkle 一致性证明、独立见证共签或抗宿主回滚。签名只能绑定已信任公钥，真实机构身份需要独立核验。
- **刷新**：仅有经过测试的零分享刷新基础函数。身份轮换、成员变更、旧胶囊的时期迁移、持久化协议状态尚未集成。
- **L3**：未实现可信硬件。程序同一进程内的对象不能充当硬件隔离。
- **大型文件**：分块执行 AEAD，但当前实验 API 在内存保存完整文件及十六进制密文，非流式交付；真实大模型需改成文件流接口。
- **状态**：请求消费和探针退役仅在当前对象/本地实验中约束。重启后的安全持久化、原子事务和多进程竞态控制待补齐。
