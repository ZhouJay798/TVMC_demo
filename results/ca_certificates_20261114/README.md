# CA 证书验证接入

实现和操作说明：[CA_CERTIFICATES.md](../../docs/CA_CERTIFICATES.md)。

三类业务公钥分别签发真实 X.509 证书。验证签名、主体/角色、算法/KeyUsage、有效期、CRL 签名和撤销状态后，才使用证书中导出的公钥；登记表中的裸公钥必须与证书一致。独立验收默认拒绝缺少外部 CA 根或预存信任文件哈希的结果包。

测试命令：`.venv/bin/python -m pytest -q`；实际完整输出见 [tests.txt](tests.txt)。

新增证书场景：
- 正常分发者签名、成员身份签名、个人 X25519 接收证书；
- 两种成员公钥分别替换裸公钥、冒用另一成员证书、冒用其他 CA、删除证书、篡改证书签名；
- 分发者公钥替换和证书用途混用；
- 接收证书撤销、CRL 回滚、过期证书和过期 CRL；
- 替换接收公钥时，在 HPKE 封装之前拒绝；
- 禁止使用不带预置信任配置的普通登记字典绕过认证；
- 撤销分发者证书后停止业务，不恢复使用旧 CRL。

原交付、双 DKG、加密评分、成员核算、合成 API 证据及反驳回归也一并运行。本次不是新的真实模型鲁棒性实验。

限制：本地私有 CA 自动为程序预设身份发证，不代表现实身份核验；CA 和成员仍在同一进程。独立根分发、CA 私钥隔离、持久撤销状态、轮换及历史签名时间戳仍需部署建设。没有自动续期或 OCSP，CRL 过期时失败关闭。
