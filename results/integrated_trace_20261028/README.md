# 登记自然指纹＋二阶补偿剪枝＋文字蒸馏：完整实测（2026-10-28）

重新注册、训练五个自然语言冗余指纹老师，没有加载之前的dense统计指纹老师。自然指纹码字由实际登记身份种子产生，不再使用脱离登记表的robust-user固定种子。每用户3个前缀/位，共768输入，256位。所有结果为真实CPU模型测量。

5个恢复会话均实际解密完整模型，SHA256一致；37项测试通过。全部21个阶段证据又由独立进程仅读公开JSON复核，与原结果一致。原式验证与研究性统计验证严格分开。

## 结论

自然老师和二阶补偿剪枝老师均5/5正确定位且原式三层全通过；文字蒸馏以及剪枝后文字蒸馏均0/5，两种检测都未指认。干净负对照不被指认。本次组合尚不能实现蒸馏后持续追踪。旧dense统计老师的成功结果不能转移到自然指纹老师。这里还重新登记了码字、训练学生时按学生上下文重新缓存并排列样本，不是只改变老师的严格单因素对照，不能据此定量归因某个因素。
