## 判定与边界

10% PPL / 90% 下一词元一致率是 Demo 自设工程门槛，不是论文硬性要求。是否能定位、效用是否通过分开报告。
攻击评估目标是代表用户 1；其他 4 用户仅完成未攻击嵌入评估。过滤与压缩独立施加，未测量压缩加过滤的联合攻击。INT8 是舍入后浮点执行，不宣称部署加速。自然触发使用相关前缀，读出依赖候选词元 logits/probabilities。
对所测过滤策略恢复定位，不代表对任意自适应过滤的安全保证，不能外推到 7B 模型。蒸馏未解决，前次短程软蒸馏与效用保持硬蒸馏反例仍成立。原密码学托管/API 流程保持独立，研究码本不是身份裁决凭据。
