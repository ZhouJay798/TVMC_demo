# 当前版本整链路验收与攻击实验（2026-11-14）

测试对象：提交 `fb43766`。真实模型为 SmolLM2-135M-Instruct（由 Q4_1 GGUF 解量化），Tiny Shakespeare 文本，5 位成员、3 人门限、3 个副本、64 位归因指纹＋16 位筛查、每位 3 个探针。三组实验分别生成新的随机码字和 CA/DKG 密钥。

## 总体结论

文件、直接 API、转发 API 三组主流程均通过；九份基准副本均只命中自己的托管方。模型平均、基座复位出现漏判，公开基座低秩截断未通过验收，因此不能宣称全面满足论文的抗攻击要求。

本次小规模实验用于检验正常链路和明确列出的攻击，不能证明全面满足论文安全目标。流程是否通过见下表；公开基座低秩截断的版本验收失败，即使主流程报告 passed，也不代表抗攻击验收通过。

## 后续优先改进

1. 将版本验收失败设为严格发行阻断条件；演示模式若继续发行，应显式标注“鲁棒性未通过”。
2. 针对公开基座差分/低秩截断、模型平均及基座复位改进嵌入，再使用独立数据、多随机种子和多个副本复测；不承诺对任意剪枝都能保留指纹。
3. 增大指纹长度并按合谋规模重新设定参数，测试多个无辜者及多种合谋；仅增加长度不能替代嵌入鲁棒性。
4. 把 CA、成员份额、见证节点拆分部署，持久化审批状态和撤销版本，继续保留当前请求核验与公开证据。
5. 补充全模型真实量化、充分 LoRA/全参业务微调及适应性去指纹实验，同时报告模型能力。
