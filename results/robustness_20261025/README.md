## 同模型、同数据、同阈值的结果

基座 SmolLM2-135M；固定模型及 WikiText-2 版本；最终测试 64 段、6,073 个 token；干净 PPL 38.858。
PPL 增幅均相对该干净模型，效用标准为增幅 ≤10% 且下一词元一致率 ≥90%。

| 比较 | 实测结果 | 结论 |
|---|---|---|
| 原指纹 → 自然多触发 + 效用 KL | 5 用户 PPL 增幅 15.28%–24.89% → 1.54%–4.13%；均定位正确 | 嵌入效用改善，5 用户均通过效用标准 |
| 新指纹逐行 INT8 → 分组 INT8 | PPL +4.19% → +1.96%；一致率 92.33% → 94.07%；均定位用户 1 | 相同 8 位量化下改善 |
| 新指纹幅度剪枝 → 二阶补偿剪枝 | 同约 30% 稀疏率，PPL +99.33% → +12.01%；均定位用户 1 | 显著改善，但后者一致率仅 80.75%，仍不通过 |
| 校准 NLL 异常输入过滤 | 原指纹完全擦除；新指纹定位用户 1，正常请求误拒绝 3.12% | 抵抗这一具体过滤器，不代表任意过滤 |
| 500 步软概率蒸馏 | 新指纹可定位，PPL +1.56% | 仅此训练预算成功 |
| **12 步软概率蒸馏** | **新指纹无法定位，PPL 仅 +0.20%** | **有效移除指纹的反例** |
| **500 步硬标签 + 效用 KL 蒸馏** | **新指纹无法定位，PPL +6.35%，一致率 96.13%** | **保留效用仍可移除指纹** |

压缩/过滤/蒸馏只对代表用户 1 测试；5 用户均做了未攻击的嵌入评估。
自然触发每位使用同一段落的三个前缀，查询从 256 增至 768，错误可能相关。
本次观察到的无辜指控为零，不构成总体误告率上界或安全性证明。
INT8 为舍入/反量化后浮点推理；不声称具有 INT8 加速或实际存储压缩。

## 同等预算的剪枝恢复补测

原始结果：[pruning_recovery/metrics.json](pruning_recovery/metrics.json)。两种方法均固定约 30% 掩码，用普通校准文本和干净教师完整词表 KL 恢复 50 步，学习率 3e-5；所有原零权重保持为零。

| 方法 + 同预算恢复 | 新版定位 | 新版 PPL 增幅 | 新版一致率 | 效用通过 |
|---|---|---:|---:|---|
| 幅度剪枝 | 用户 1 | 47.68% | 63.40% | 否 |
| 二阶补偿剪枝 | 用户 1 | 11.17% | 81.44% | 否 |

这是干净主干压缩和恢复后重新装载相同指纹适配器的配对实验，恢复阶段的指纹头为零；不是对水印头和主干联合恢复，也不是从水印教师提取模型。没有使用秘密触发器校准或训练恢复。恢复进一步改善了部分指标，但没有达到原定效用门槛。
