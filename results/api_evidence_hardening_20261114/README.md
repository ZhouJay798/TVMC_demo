## 版本、限制和复跑

新采集证据签署 time、finished、evidence_version=2。历史 v1 保留只读核验，但不能证明响应完成时间；独立验证输出会标明版本及 api_completion_times_verified。签名时间仍依赖诚实采集者本机时钟，不是外部时间戳认证。

组占用依赖当前单写者日志；多进程并发事务、独立份额保管、独立 CA、可信状态持久化仍需部署工作。失败必须改用新组，不能自动重试已披露组。

初次真实模型运行在发行前主动中断，以切换到最终占用实现；real_relay_interrupted.log 不是通过证据。tests_initial79.txt 是中间版本测试，最终以 tests.txt 的 81 项为准。
