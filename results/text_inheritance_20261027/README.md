# 实际生成文字指纹：实测成功定位，但联合验收未通过

2026-10-27，两轮真实 SmolLM2-135M CPU 实验；35 项测试通过。原入口、统计指纹权重、原蒸馏训练函数未改动。新增可选采样分支，学生仅从实际生成 token 学习，不接收指纹密钥。生成 64×32=2048 tokens，学生 500 步、KL=10，预算与旧失败对照相同。

## 原评估集回归（test offset 192，5783 tokens，干净 PPL 30.062）

| 实验 | 定位 | 学生 PPL | 增幅 |
|---|---|---:|---:|
| 原 soft12 | 用户1 | 30.614 | 1.84% |
| 原 soft500 | 用户1 | 31.375 | 4.37% |
| 原 hard-KL10 | 用户1 | 30.366 | 1.01% |
| 原生成文本 KL10 | 失败 | 31.079 | 3.38% |
| 新采样偏置0.5，生成文本 KL10 | 用户1 | 31.166 | 3.67% |

前三项与原结果一致。但偏置0.5令老师实际输出分布 PPL 增加28.28%，不能作为低损伤成功方案。初轮还试过1.0；全部验证集结果及生成 token 在 initial 中，不隐藏失败。

## 较小强度候选：独立留出文本（test offset 256，5616 tokens）

看到初轮老师效用损失后，仅在验证集比较0、0.1、0.2；0和0.1的学生不能定位，0.2成功。选择0.2后才评估另一段留出文本。干净 PPL **36.366**，不能与30.062基准的绝对PPL混比。

| 实验 | 定位 | PPL | 相对本组干净基座 |
|---|---|---:|---:|
| 原生成文本蒸馏学生 | 失败 | 37.543 | +3.24% |
| 0.2偏置文字蒸馏学生 | 用户1 | 37.731 | +3.75% |
| 0.2偏置老师实际输出 | 不作为学生检测 | 40.025 | +10.06% |
| 原 soft12 回归 | 用户1 | 36.914 | +1.51% |
| 原 soft500 回归 | 用户1 | 37.730 | +3.75% |
| 原 hard-KL10 回归 | 失败 | 36.703 | +0.92% |

学生指纹 p=0.000488，与预设每用户阈值0.002比较通过，只指认用户1。干净文本训练负对照未被指认。但老师增幅10.0608%略超10%门槛；原硬标签学生在新语料上的p=0.002441也未通过0.002。没有放宽阈值，所以低强度轮返回2、passed=false。该硬标签失败揭示原方法对检测语料的敏感性，不是新采样分支改动原参数造成的：原评估集三项回归全部一致。

学生下一词元一致率88.34%，也未达到原90%一致率诊断目标；不能宣称全部性能不受影响。原soft500同样低于90%。

## 限制及证据

- 完成了“输出文字携带信号，并被此次学生学到”的功能；尚未完成稳定、低损伤、跨所有检测文本的联合验收，保留为可选实验功能，不替换原默认路径。
- 这是生成接口层偏置，拿走权重绕过该接口不受保护。学生检测仍需要完整概率表，不是仅看聊天输出即可识别。
- 只测用户1、单次生成随机种子及同架构输出头学生；没有多用户、多随机种子、改写攻击或完整能力验证。不能把随机密钥检验阈值等同于真实部署误报率实测。
- 两轮原始 metrics.json、run.log、生成token和执行入口快照保留。最终入口仅额外加入源码哈希记录；初轮入口完成即返回0，因此应看passed字段；最终入口验收失败返回2。
- 参数、Windows运行步骤见 [操作说明](../../docs/TEXT_INHERITANCE.md)。默认仍运行原方案。
