## Windows复现

```powershell
git pull --ff-only
.\.venv\Scripts\python.exe run_dense_bias_check.py --model-path ".\outputs\你的原始运行目录\decrypted_model" --natural-dir ".\outputs\你的自然指纹完整实验目录" --output ".\outputs\dense_bias_local" --offline
```
